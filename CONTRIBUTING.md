# Contributing

Thanks for helping make Free LLM Models better!

## Quick start

```bash
npm install          # root (updater)
cd web && npm install
cd web && npm run lint && npm run build && npm test
npm test             # root: node:test suite
```

## Project rules

- Do not hand-edit `web/public/models/*.json`, `index.json`, `free_models.json`, or `openrouter_free_models.json` — they are generated by `node get_openrouter_free_models.js` or `scripts/update_data.sh`.
- Keep changes minimal; this repo is small by design.
- After web changes, verify with `cd web && npm run lint && npm run build`.
- If you change documented behavior, update `README.md` in the same PR.

## Data updater

Provider keys are optional at runtime (see `.env.example`). Only OpenRouter works keyless.
Use `PROVIDERS=openrouter,groq` or `--providers openrouter,groq` to scope a run.
Never run the updater casually — it rewrites tracked JSON and the cron script can push to `main`.

## Agent readiness

The site is hosted on GitHub Pages at `https://free-llm-models.custats.com` (Vercel as legacy). Discovery docs live under `web/public/.well-known/*` and at the site root (`robots.txt`, `sitemap.xml`, `llms.txt`, `llms-full.txt`, `Auth.md`). See `agent-ready-plan.md` for the Pages vs Vercel split and manual DNS steps.

## Issues and PRs

- Search open issues before filing a new one.
- For harness smoke-test changes, use disposable credentials per `docs/manual-harness-validation.md` and never commit credentials.

## Security

See `SECURITY.md` for reporting vulnerabilities. See `.well-known/security.txt` for the canonical contact.
